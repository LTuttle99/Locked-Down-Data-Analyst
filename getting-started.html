Welcome to the Data and Analytics Hub

This is a quick guide to getting started. It takes about two minutes to read, and you won't need anything besides the code you were given.

1. Getting In

When you open the hub, you'll see a black screen with a number pad and the words "Enter Access Code." Type in the code you were given. That's it — no username, no password, no account to create.

If you type the code correctly, you'll see a quick "Access Granted" message before the hub opens up. If you mistype it, the screen will shake and let you try again.

2. What You'll See

Your code unlocks a specific set of tools picked for your team — not the whole hub. That's intentional: everyone sees exactly what's relevant to their work, and nothing they don't need. If you think you're missing a tool you need, just reach out (see the bottom of this page).

There's a search box at the top of the page if you're looking for something specific by name.

3. Using a Tool

Click any card to open that tool. Each one does one thing — cleaning up a file, comparing two documents, building a chart, generating a QR code, and so on. Most either ask you to upload a file or just let you start typing right away.

Everything runs right in your browser. Nothing you upload or type is ever sent anywhere or saved on a server — there isn't one. Closing the tab clears whatever you were working on, the same way closing a document without saving would.

A Few Things to Know

  • •You'll need to re-enter your code each time you open the hub — it isn't remembered between visits, by design.
  • •Works on your phone or tablet too — the code screen and every tool adjust to a smaller screen.
  • •Nothing to install and nothing to update — you're always using the latest version.

Questions or Suggestions?

If your code isn't working, you need access to a different tool, or you just have an idea for something that would make this more useful, email Logann.
