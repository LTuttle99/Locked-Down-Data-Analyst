Welcome to the Data and Analytics Hub

This is a quick guide to getting started. It takes about three minutes to read, and you won't need anything besides the code you were given.

1. Getting In

When you open the hub, you'll see a black screen with a number pad and the words "Enter Access Code." Type in the code you were given. That's it. No username, no password, no account to create.

If you type the code correctly, you'll see a quick "Access Granted" message before the hub opens up. If you mistype it, the screen will shake and let you try again.

2. Finding Your Way Around

Your code unlocks a specific set of tools picked for your team, not the whole hub. That's intentional: everyone sees what's relevant to their work and nothing they don't need. If you think you're missing something you need, just reach out (see the bottom of this page).

Tools are grouped into four sections so you can scan by what you're trying to do:

  • •Explore and Analyze for understanding a file you already have: totals, trends, forecasts, charts, and summary statistics.
  • •Clean and Combine for tidying up messy data or putting two files together.
  • •Generate and Encode for making something new, like sample data or a QR code.
  • •Text and Dev Utilities for everyday odds and ends: comparing text, checking a date, converting units.

There are three ways to reach a tool. Click its card, type in the search box at the top to filter, or press Ctrl and K together (Command and K on a Mac) to open a jump box, type a few letters, and press Enter. Tools you've opened recently also appear as shortcuts near the top of the page.

3. Using a Tool

Each tool does one thing. Most either ask you to pick a file or let you start typing right away. Nothing installs, and there's no setup.

If you want to try something without hunting for a file first, several tools can load their own example data. The Data Analyzer has a "Load sample data" button, the SQL Workbench has "Load Sample Tables", and the Test Data Generator builds a file to whatever shape you describe. Those are good places to start if you just want to see what a tool does.

Most tools let you download the result as a CSV or Excel file when you're done, so you can carry it into a spreadsheet or into another tool here.

4. Where Your Data Goes

Nowhere. Every tool runs inside your own browser tab. There is no server behind this hub to send anything to, so files you pick are read on your own machine and never uploaded. Closing the tab clears whatever you were working on, the same way closing a document without saving would.

Two small exceptions worth knowing. The hub remembers which tools you opened most recently so it can offer shortcuts, and the Data Analyzer can save your filter setups as named views. Both are kept only in your own browser on your own device, and neither one stores any of your data. Your access code is never saved anywhere.

A Few Things to Know

  • •You'll need to re-enter your code each time you open the hub. It isn't remembered between visits, by design.
  • •Works on your phone or tablet, though the tools that show wide tables are easier to read on a laptop.
  • •Nothing to install and nothing to update. You're always using the latest version.
  • •Very large files (hundreds of thousands of rows) will feel slow, because all the work happens on your own machine rather than on a server.
  • •When a tool reads an Excel workbook, it uses the first sheet.
