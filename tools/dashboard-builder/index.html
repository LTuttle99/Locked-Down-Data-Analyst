Dashboard Builder

Build and download

Build a dashboard by picking the visuals, saying what each one measures, and adding slicers people can filter with. Load a CSV or Excel file and it draws from your real data. Download it as a single HTML file, or send the link.

1. Your data

Load a CSV or Excel file and you pick from its real columns. Skip it and you still get the layout, with placeholder numbers. Nothing is uploaded anywhere.

2. Visuals

3. Slicers (optional)

Controls that let whoever opens the dashboard filter every visual at once.

Share it

The link carries the layout but not your file, so whoever opens it attaches their own copy of the data. Download HTML gives you a single self-contained file with the data already in it, which is usually what you want to hand someone.
