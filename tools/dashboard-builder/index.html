Dashboard Builder

Build and download

Build a dashboard by picking the visuals, saying what each one measures, and adding slicers people can filter with. Download it as a single HTML file, or send the link.

How this works

  1. Point it at your data. Choose a CSV or Excel file, or paste a Google Sheets link. The tool works out which columns are numbers you might total and which are categories you might group by, so everything after this is picking from dropdowns rather than typing column names. You can skip this and design the layout first with placeholder numbers.
  2. Say what you want. Type it in plain words, like revenue by region, total orders, revenue over time, and the visuals get built and bound for you. Or add them one at a time with the buttons. Either way you can adjust anything afterwards.
  3. Add slicers if people need to explore. A slicer is a control on the finished dashboard, so whoever opens it can narrow every visual at once, by region or date range for example.
  4. Hand it over. Download HTML gives you one file containing the dashboard and its data, which works on its own with nothing else installed. The link carries the layout but not the data, so whoever opens it attaches their own copy.

Nothing you load is uploaded anywhere. Files are read inside your browser, and a Google Sheet is fetched straight from Google by your own browser.

Show on the dashboard

1. Your data

Load a CSV or Excel file and you pick from its real columns. Skip it and you still get the layout, with placeholder numbers. Nothing is uploaded anywhere.

or

The sheet has to be readable without signing in: open Share and set General access to "Anyone with the link". A dashboard built from a sheet re-reads it every time it is opened, so it stays current.

2. Visuals

Separate each one with a comma or a new line.

3. Slicers (optional)

Controls that let whoever opens the dashboard filter every visual at once.

Share it

The link carries the layout but not your file, so whoever opens it attaches their own copy of the data. Download HTML gives you a single self-contained file with the data already in it, which is usually what you want to hand someone.
