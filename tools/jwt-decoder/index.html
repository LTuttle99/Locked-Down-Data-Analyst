JWT Decoder

Header · payload · expiry
This decodes a token so you can read it. It does not verify the signature, which would need the issuer's secret or public key. Treat anything you read here as unverified, and remember that a token is a live credential while it is valid: decode test tokens rather than production ones where you can.
