SQL Workbench

Query files with SQLite

Load one or more CSV, Excel, or JSON files, then query them with standard SQLite. Each file becomes a table, so you can join across them, group, and aggregate. Everything runs in your browser and nothing is uploaded anywhere.

Click a column name to insert it. Names with spaces need double quotes, like "Order Date".

Press Ctrl+Enter (Cmd+Enter on Mac) to run.
